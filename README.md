# Manager Group

Manager Group é um sistema web para gerenciamento de projetos e tarefas. Ele é composto por uma API de backend e um cliente frontend.

## Estrutura de Pastas

- **backend/** – API construída com AdonisJS 6. Fornece endpoints REST, autenticação e modelos de banco de dados.
- **frontend/** – Aplicação React criada com Vite e estilizada com Tailwind CSS.
- **GUIA_ATUALIZACAO.md** – Guia para atualizar o projeto em um servidor.
- **setup_project.sh** – Script com instruções de configuração inicial.
- **update_project.sh** – Script para atualizar dependências e código.

Para instruções detalhadas de configuração e uso de cada stack, consulte:

- [README do Backend](backend/README.md)
- [README do Frontend](frontend/README.md)
